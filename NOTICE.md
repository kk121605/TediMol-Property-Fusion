# Source attribution and reuse

This is Yikun Luo's participant-maintained stage-2 research portfolio repository. The contributor confirmed that the code and related content in the requested scope may be public. Public visibility does not create a blanket licence for all inherited material.

The research-group-provided TediMol backbone, JoPMol-style reference and other inherited code retain their respective ownership. No repository-wide licence was found in the supplied TediMol materials, and this release does not relicense them. Obtain the relevant rightsholders' permission for reuse beyond existing grants.

The A2 numerical encoding follows Regression Transformer's public method and official numerical function. The official IBM snapshot's MIT licence is retained in `third_party/Regression-Transformer-LICENSE`. The inherited diffusion lineage includes OpenAI improved-diffusion; its MIT notice is retained in `third_party/improved-diffusion-LICENSE`. Existing source comments identifying earlier diffusion lineage remain intact.

The A3 code adapts a conditioning idea from Graph DiT rather than copying the complete graph model. The inspected Graph DiT snapshot lacked a root licence; no new licence grant is asserted on its behalf. BioLinkBERT is an external dependency; no encoder weights are redistributed.

The CPU publication wrapper, tests, verifier and English documentation are distinguished from the recovered source in `docs/provenance.md`. Source hashes identify bytes, not ownership or a universal right to reuse. No original manuscript PDF, private training CSV, large checkpoint or text cache is included.
